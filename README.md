# 心印 · dsh-heartprint

**⚠️ 安全提示：1.1.0 之前的版本（1.0.0 / 1.0.1 / 1.0.2）没有经过安全加固，存在已知的加固缺失（设置接口无默认拒绝与限流、名字未做文件名净化、路径未校验）。请不要下载或使用这些旧版本，请使用 1.1.0 及以上版本。**

心印是一个**记忆类插件**。

- 可以设置**性格**、**人格**，给它**取名字**。
- 有**情绪**：它会表达情绪，介意勿下载。
- 有**淡忘**功能：只淡忘一些琐碎、无用的信息；重要的事情会经过分析保留。
- 会记得**你跟它之间最重要的事情**。
- **特殊事件**功能：对你有特殊意义的事情会被记住。

除此之外不介绍其他内容。

## 安装

```text
plugin_manager install_bundle   <插件文件夹绝对路径>
```

或从 npm 安装：`npm i dsh-heartprint`

要求：DSH >= 0.2.1-rc.1，Node.js >= 20。不联网、不上传。
